# Notes: Slide decks: the shared light system and grammar

Moved word for word from CLAUDE.md on 2026-09-27 (the full original is `git show f7f52ee:CLAUDE.md`). CLAUDE.md holds the current state and the standing rules; this file is the history behind them. Entries keep their original order, and where two disagree, the later-dated one or the one marked SUPERSEDES wins. Add new entries at the top, directly under this paragraph.

- **Slide decks are LIGHT and share ONE system (2026-08-03, per user "i think we need to slides light mode" → chose "Both decks, one shared light system"). This SUPERSEDES the palette-is-per-project rule below — do not re-split the palettes.** Coffee Chat was converted from the site's dark canvas to **Hearth's ramp, which homewiseslide already used**, so the two decks are now literally value-identical: canvas `#F6F4EF`, card `#FFFFFF`, deep well `#EEEAE1`, ink `#1A1A17` / `#6B6B65` / `#A8A8A1`, hairlines `#E7E5DE` / `#CFCEC7` / `#A8A8A1`, and shared flag colours (good = sage `#4F6942` on `#E2E8DC`, bad = ember `#8E601E` on `#F5E4CE` — Homewise's `.tick--*` convention, now Coffee's `.flow-ic--*`/`.tag--*` too). **The ONLY per-deck difference is `--accent`** (Coffee `#2456D6`, a deepened Litespace blue that holds contrast on cream; Homewise sage) plus Coffee's lavender `--plate: #d0d1fd`. Coffee kept its old token NAMES (`--bg`/`--text`/`--line`) and just repointed the values, which is why the diff is small; Homewise needed no change at all. **Four structural rules that make a light deck work, all learned the hard way here:** (1) **the letterbox must stay ink** — a new `--letterbox: #1A1A17` backs `html/body/.deck` while `.slide` is cream, or the light fixed chrome (brand, nav circles) vanishes into a cream frame. (2) **The two bookends stay INK** — `.slide--title, .slide--end { background: var(--letterbox) }`; the warm→blue gradient is a *wash on the dark base*, and without that base the slide inherits cream and the white wordmark washes out completely (this shipped broken for one render and is the most visible failure mode). (3) **The mid-deck peak inverts**: Coffee's Reflection went from `.slide--lav` (light-on-dark-deck) to `.slide--ink` (dark-on-light-deck), matching homewiseslide's Outcome slide — a light deck gets one dark peak. (4) **Flow-chart SVGs carry INLINE white** (`stroke="rgba(255,255,255,0.4)"` on 18 arrows/connectors plus white marker fills) which is invisible on cream — those attributes had to be recoloured in the markup, not just the CSS. **(5) EVERY fixed chrome element lives in the ink letterbox, so it must use `--on-dark*`, never `--text`/`--text-muted`** — `.deck-brand`, `.deck-hint` (+ its `kbd`), `.navbtn` (all three circles), `.navbtn--comment.on`, `.cmt-count` and `.cmt-bar`. This one is invisible in a contact sheet: the nav circles still drew their light borders, so they looked present, but the chevron/bubble SVGs are `stroke: currentColor` and inherited ink — **three empty rings on a dark letterbox**, which is exactly how the user reported it. **Method note: the first leftover-scan only grepped for WHITE literals and therefore missed the inverse class of bug entirely — dark surfaces that now need to be light.** A second scan for dark literals found `.cmt-pop` (`rgba(20,20,20,0.97)`) and `.pin` (`#1c1c1c` with `color: var(--text)`), i.e. ink text on an ink popover and an invisible pin number. **Scan BOTH directions after any palette flip.** Also easy to miss: `.cta` used `var(--text)` but only ever renders on the ink sign-off (needs `--on-dark`), and `.cmt-ava` was a white tint inside a popover that is now white. Verified end to end: comment mode opens a white card with ink text and cream inputs, and all three nav icons read.
- **Slide-deck visual grammar (established 2026-07-31, user-approved on homewiseslide's deck.gallery reskin — the LAYOUT grammar still applies to any future deck; the palette-is-per-project clause is superseded by the shared light system above):** editorial print, not boxed cards. Source patterns: deck.gallery's Geist*Studio Impact Report (stat rows + in-slide document chrome), Reece Evans Portfolio (metadata-columns cover + giant wordmark), Lefty (persistent brand footer). The PALETTE is per-project (homewiseslide wears Hearth; another deck would wear its own case study's tokens) — the grammar below is what transfers. (1) **Every slide is a framed page**: in-slide header row (section label left, static "<Project> · Case study" right via `.s-label::after`, full-width hairline under) + JS-injected folio footer (hairline, "A case study by Chang Mou" left, "NN / NN" right). No separate letterbox counter — the folio carries the number. (2) **Top/bottom composition**: title zone anchored top, artifact block pushed to the bottom via `.push { margin-top:auto; padding-top:44px }`, folio closing the frame. Never leave content floating in the top half with a void below — that was the exact "ugly" the reskin fixed. Full-height splits get `flex: 1 1 0; min-height: 0` so they center between header and folio. (3) **No boxed cards**: stats are full-width hairline ROWS (oversized numeral ~112px left, annotation pinned to a right ~620px column); triads/stages are rule-topped COLUMNS with a tiny accent-color index (01/02/03), no background fills; hero figures (the money numbers) run 96–128px. (4) **Extreme type contrast**: ~13.5px/0.2em caps labels against 76px titles (54px compact variant for artifact-heavy slides; 46px in media slides' 2-col `.media-head` where the annotation sits right so the artifact keeps its height), ~96px ink statement slides, 170–300px display on the bookends. Single-weight rule applies as everywhere (400/500 only, explicit `font-weight` on every heading). (5) **Cover + sign-off are Reece-style dark bookends**: tiny metadata columns top (Role/Team/Timeline/Built with), giant `white-space:nowrap` wordmark bottom-left + small description bottom-right — SIZE THE PAIR TOGETHER (wordmark px + sub max-width; 300px/520px overflowed, 280px/430px fits), brand texture (dot grid) reserved for the two bookends only. (6) **One mid-deck ink statement slide** at the payoff beat (flat dark + quiet accent wash, no texture) for rhythm. (7) **One accent color** for chrome (solid progress bar; no decorative multi-color ramps). (8) Radius only on media frames (~8px) and pills — layout structure is drawn with hairlines, never rounded boxes.
