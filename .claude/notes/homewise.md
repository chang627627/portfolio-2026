  - **How the clips were made (the recorder lived in the session scratchpad; rebuild it from this if needed).** Puppeteer drives the live app at the originals' page size, 1728x1032 (the sidebar's right edge at x=270 of 1920 in every original: Safari full screen on a 1728-point display; a 1400 window shows everything 23% too big), captured at 2x by CDP screencast, each frame scaled to 1920x1146 under a 58px strip of Safari's toolbar cut from the original, so 1920x1204 like the originals. Headless Chrome hands over only about 27 frames a second, so the page runs in slow motion while captured (x4: performance.now, Date.now, rAF, timers scaled in the page; CSS and Web Animations by CDP Animation.setPlaybackRate; programmatic and CSS smooth scrolls replaced by page-clock rAF animations, since the app's chat uses Tailwind's scroll-smooth) and the frames are resampled to 60fps by page time. The cursor is not filmed: the page logs its exact path and each glide's curve, and the compositor draws a Chrome-rendered sprite (macOS-style arrow, hand, I-beam over selectable text, 0.78 scale, soft shadow) on every output frame at that frame's own time, so glides ease evenly (filmed, they stepped 74, 14, 88 px from capture-timestamp jitter). Safari's scrollbar is styled in (an 11px gutter, a 13% black thumb, no track; `ignoreDefaultArgs: ['--hide-scrollbars']`, Puppeteer hides them by default), which also puts the layout on the originals' pixels (title x 374 vs 375, card edge 1805 vs 1805). Image responses are rewritten as immutable (the app serves photos with max-age=0, so a remounted page re-validated them and painted a frame without them) and images load eager and decode sync; one blank-tile fade frame in track (f143) was held from f142. Encoder: H.264 High, 6 Mbps, sRGB values tagged BT.709 primaries and matrix with the sRGB transfer, moov first (fast start); on a colour chart it decodes within 3 levels in Chrome and AVFoundation (Safari), where the untagged files of the first takes showed midtones up to 11 levels light in AVFoundation and a CoreGraphics BT.709 conversion lifted shadows by 14 in Chrome. The originals' Safari file pickers became short pauses on the upload buttons.
