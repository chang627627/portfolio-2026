- **Nav link contrast (fixed 2026-07-26, UI-craft review P7):** `.nav-links` colour moved `--text-muted` (#888) → **`--text-soft` (#a0a0a0)**. At 13px over the animated hero gradient the muted grey measured **3.44:1 worst-case** across the irisFlow cycle (sampled 6 frames × 3 links from rendered pixels) — below WCAG AA's 4.5:1 for normal text. #a0a0a0 measures **4.67:1** there and ~7.6:1 on the dark pages. Deliberately not brighter (0.72 white would hit 7.13:1) so the inactive links stay clearly secondary to the white `.nav-active` link. Note this is shared chrome, so case-study navs get the same strictly-better contrast. **The audit's companion claim — that `.footer-links`/`.footer-copy` fail AA on the footer's amber band (3.40:1 / 2.99:1) — did NOT reproduce and was NOT acted on:** it reasoned from the CSS gradient stops (amber `rgba(255,190,35,0.64)` at 88%/100%) but the links actually render over the *red-orange* part of the gradient, sampled `rgb(160,62–67,38)` at every viewport tested (1440×700/900/1200/1600, 1024×768), giving **5.61–5.81:1 for links and 4.64–4.78:1 for the © line — both pass**. The proposed dark scrim on `.footer-bottom` would have dimmed the footer for nothing. **Lesson: compute contrast from rendered pixels, not from stacked CSS colour values.**
